🔍 Filter Guide & Examples

Purpose: Filter BigQuery data to match specific criteria from your API source

Common Use Cases:

  • Account Filtering: account_id = 'abc123'
  • Status Filtering: status = 'active' OR enabled = true
  • Date Range: created_date >= '2024-01-01' AND created_date <= '2024-12-31'
  • Multiple Conditions: region IN ('us-east', 'eu-west') AND tier = 'premium'

💡 Tip: Use standard SQL WHERE clause syntax. Leave empty to compare all BigQuery records.
